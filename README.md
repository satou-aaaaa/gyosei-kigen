# 行政の期限（gyosei-kigen）

役所の処分への審査請求・再調査の請求・再審査請求、処分の取消訴訟、パブリックコメント、国の文書の情報公開・自分の個人情報の開示の場面を読んで、その期限（2週間・30日・1か月・60日・3か月・6か月・1年）を当てる1日5問の学習ゲーム。正解したら、どのきまりか（不服申立て／裁判と意見公募／情報の開示）も選ぶ。行政のきまりの学習に。

遊ぶ: <https://satou-aaaaa.github.io/gyosei-kigen/>

- 中身は e-Gov 法令検索の行政不服審査法（<https://laws.e-gov.go.jp/law/426AC0000000068>）第18・54・62条、行政事件訴訟法（<https://laws.e-gov.go.jp/law/337AC0000000139>）第14条、行政手続法（<https://laws.e-gov.go.jp/law/405AC0000000088>）第39条、行政機関情報公開法（<https://laws.e-gov.go.jp/law/411AC0000000042>）第10・11・13条、個人情報保護法（<https://laws.e-gov.go.jp/law/415AC0000000057>）第83条に書いてある期限だけです（2026-11-18 に読んだ今の条文）。
- 説明は条文を、短く言いかえたものです。それぞれの法律の特別の不服申立て・自治体の情報公開条例・手数料は省いています。公式の情報の代わりではありません。実際のことは、処分の通知に書いてある教示や総務省の案内、専門家に確かめてください。
- 30日と1か月はほぼ同じ長さなので、選び肢に両方は出しません。
- 2段目は、きまりの種類で分けています。
- 記録は遊ぶ人のブラウザだけに残り、外へ送りません。
